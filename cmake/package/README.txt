RailsimPlus (ポータブル版)

■ 使い方
1. この ZIP を好きなフォルダへ展開します。
2. RailsimPlus.exe を起動します。インストールは要りません。
3. 右上のメニューの「ゲーム設定」→「ルートを管理…」→「追加…」で、
   RailSim II のフォルダ(Rail・Train などのフォルダが入っているところ)を選びます。
   RailSim II 本体・プラグイン・.rs2 は付属していません。
4. 初回に「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。

■ 動作環境
- Windows 10 / 11 (64bit)
- Direct3D 12、Shader Model 6.0、Resource Binding Tier 3 に対応した GPU

■ 保存されるもの
- 設定(settings.dat)、保存したレイアウト(saves フォルダ)、スクリーンショットは、
  この exe と同じフォルダに保存されます。フォルダごと移せば、そのまま引っ越せます。
- 書き込めない場所(Program Files など)へ展開したときは、設定だけ
  %LOCALAPPDATA%\RailsimPlus へ保存されます。
- 使わなくなったら、フォルダごと削除してください。

■ 更新
- 新しい版が出たら、設定の「バージョン情報」から「更新する」で更新できます。
  ダウンロードして展開したあと、「再起動して更新」で差し替わります。
- 更新したあとに起動しなくなったら、RailsimPlus.exe.bak を RailsimPlus.exe に戻してください
  (同じフォルダの .bak が付いたファイルを、.bak を外した名前に戻します)。
